# Neural Networks: Zero to Hero

This repository contains my implementations and exercises following Andrej Karpathy's excellent "Neural Networks: Zero to Hero" YouTube series.

## Labs Overview

### 0. Micrograd
Building a neural network from scratch, implementing backpropagation and autograd engine.

### 1-5. Makemore Series
Character-level language models with progressive improvements:
- **Lab 1**: Bigram model (simple probabilistic approach)
- **Lab 2**: Multi-layer perceptron (MLP) implementation
- **Lab 3**: Batch normalization and deeper networks
- **Lab 4**: Convolutional approaches
- **Lab 5**: WaveNet-style architecture with dilated convolutions

### 6. Build GPT
Implementing a GPT (Generative Pre-trained Transformer) from scratch, understanding attention mechanisms and transformer architecture.

### 7. Tokenizer
Building and understanding tokenization algorithms (BPE, etc.) for processing text data.

### 8. Build GPT-2
Reproducing GPT-2 architecture and training larger-scale language models.
